# Video Dehydrator for Mac

This repository is the Mac build brief. The whole instruction file is [BUILD-MAC.md](BUILD-MAC.md). Apply [CHANGES-2026-10-16.md](CHANGES-2026-10-16.md) on top of it. That note is the Windows 1.0.7 behavior.

Build the Mac program from that file. It matches the shipping Windows program's jobs, list, and rules, with Mac replacements for sleep, shutdown, share mounts, and updates.

Windows stays the primary version. Before you change the Mac app, pull the private notes repository and read [windows.md](https://github.com/philipvern-dot/video_dehydrator_notes/blob/main/windows.md). When you finish, add a dated section to mac.md in that same repository and push it. Write only in mac.md.

Do not publish a release from this repository until asked.
