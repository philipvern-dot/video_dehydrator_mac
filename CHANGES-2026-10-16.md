# Changes from the Windows 1.0.7 release

Apply this file on top of [BUILD-MAC.md](BUILD-MAC.md). Where the two disagree, follow this file. These are the final Windows behaviors from 16 October 2026. The Windows program that shipped them is version 1.0.7.

The scan lists more files than the original brief. It does not list fewer. A file that was Bloated is still listed.

## Ratio

The heading is Ratio. A saved column order that says Over is read as Ratio.

Ratio is still the whole file's GiB/h divided by the budget. It is shown with two decimal places, such as `1.20x` and `2.00x`. `1.00x` means the file is on the budget line. A value above 1 that would round to `1.00` keeps another digit, up to four places, so `1.04x` and `1.004x` stay visibly over the line. The first click on Ratio still sorts the largest ratios first.

Green, yellow, and red stay on Bloated and Failed rows only. Slight is under 1.5 times, Heavy is under 3 times, and Extreme is 3 times or more. A ratio under `1.00x` is not colored.

## Can shrink

A file under the budget line is listed when all of these are true:

- The picture rate was read.
- That rate is at least 40 percent of the whole-file rate.
- That rate is above 105 percent of the target video rate.
- The New size estimate is smaller than the file.

The status is Can shrink. The row starts checked. The Ratio cell is not colored. Select slight, Select heavy, and Select extreme leave these rows alone. Select all, the folder list, Select folder, estimated savings, and Optimize include them.

These stay off the list, as before:

- Dolby Vision.
- A file whose length or picture size cannot be read.
- A file on or over the line whose picture is already within 5 percent of the target. The extra size is audio.
- A file remembered because an earlier new copy was not smaller.
- A file under the line whose picture rate is missing or too small to trust.
- A New size that starts with ~. That guess ignores the audio, so it is not used to add an under-the-line file.

HEVC and AV1 still use the higher file line. A file under that line is Can shrink when its picture is above the target rate. Raising a budget removes a listed file only when its picture is no longer above the new target. If the picture is still above that target and the whole file is under the new line, the row stays and its status becomes Can shrink.

The scan summary counts both groups, for example `4 bloated (4.20 GiB). 6 can shrink (8.10 GiB).`

## ~Savings

Add a sortable column named `~Savings`, after Space Saved. It is the current size minus New size, before a convert. It is blank when there is no smaller estimate. A rough estimate is prefixed with `~`. The first click sorts the largest estimate first. After a convert, the cell clears and Space Saved shows the real result. If a saved column order has no `~Savings` heading, insert it just before Space Saved.

## Showing all

Add a Showing all button under the video list. It opens a checkbox for each group, in this order: Can shrink, Bloated, Slight, Heavy, Extreme, Failed, Skipped, Ready to delete, Finished. The boxes start unchecked, and every row stays on screen.

Check one box to show only that group. Check more boxes to add those groups. A row stays when any checked box matches it. To see only Slight, leave Bloated unchecked as well as Heavy and Extreme. The button then reads `Showing Can shrink, Slight`, using the checked names in the order above.

A hidden row is unchecked, so Optimize does not take it. Select shown checks the rows still on screen whose status is Bloated, Can shrink, Failed, or Skipped, and clears the other checks. Clearing every box shows the full list again. The scan itself is unchanged by these boxes.

## Buttons

The convert button is labeled Optimize. It still shrinks every checked Bloated, Can shrink, Failed, and Skipped row.

The graceful stop button is labeled Stop after current file. It lets the file already encoding finish its check and replace, then leaves the rest of the batch checked. Continue clears that request while the same file is still running. Cancel still stops the file in progress.

Every button has a tooltip, including Optimize, Stop after current file, Continue, Showing all, and Select shown. A grayed-out button still shows its tooltip.

## Compare

Compare is unchanged. The held original is on the left. The new file is on the right. The sound is the new file.
